## Specs
S1. «Necesito que añadamos campos para saber el país, el estado o provincia (o equivalente), y la dirección (incluyendo mapa de google) para las barberías.»
S2. «Esto con el fin de mostrar la dirección y el mapa cuando se reserva una cita.»
S3. «Además, en un futuro cuando hagamos un portal para ver las barberías registradas en barberhub, se pueda filtrar facilmente por barberías cercanas, barberías en la ciudad, etc.»
S4. «Tuve un problema con google cloud. Creo que lo mejor será poner la dirección manualmente y un pequeño <a> que referencie a google maps para poder copiar la direccion exacta y el embed para poder pegarlo en el formulario.» — replace autocomplete with manual fields, small Google Maps link and pasteable embed input.
S5. «Tuve un problema con google cloud.» — remove the Cloud/SDK/API-key integration; consumer Google Maps sharing/embed only, no account configuration required by this feature.
S6. «Solo instrucciones al finalizar» — standing setup-delivery preference: no .env, .env.example or README reads/edits; usage instructions in final reply and form help.
S7. «Google completa la dirección; coordenadas manuales» — previous autocomplete portion superseded by S4. Existing independent manual coordinates remain optional for future proximity data and legacy map fallback; pasted embed can show the map without coordinates.
S8. «Oye, tambien dile al worker que quiero el nombre del pais en lugar de su codigo de dos letras» — forms and public booking addresses display Spanish country names; no user needs to type ISO codes. Existing ISO2 storage/payload remains internal and compatible with future filtering; nullable country and all previously supported countries remain.
