# Alta de cuentas nuevas de barbero por owner
Branch: `frontend-appointments` · Scope: alta tenant de cuenta nueva con membresía, perfil de barbero e invitación segura por correo.
Intent: permitir que owner/admin incorpore personas sin una cuenta previa, reutilizando el reset token de Laravel para configurar contraseña/verificar correo; no cambiar invitación de usuarios existentes.

## Specs

S1. User request (verbatim): “Puedes hacer que los owners de las barberías puedan crear barberos?”
S2. User decision (verbatim selection): “Sí, cuenta nueva”. La alta admite nombre y correo de persona nueva; crea cuenta BarberHub, membresía activa de rol barbero y perfil activo asociado a la barbería actual.
S3. User confirmed secure onboarding (verbatim option selected): “Sí, invitación por email”. El owner/admin ingresa nombre y correo; se envía enlace de un solo uso para que la persona establezca su contraseña y verifique su correo. El flujo no expone ni pide contraseña inicial del barbero.
S4. La última decisión del usuario reemplaza el botón “Guardar miembro” de Equipo por un acceso a Barberos, después de recibir esta aclaración: la acción existente para agregar cuentas se dejaría de enviar desde Equipo. El usuario eligió “Reemplazar “Guardar miembro””. Mantener la invitación segura: no cambiar, reutilizar ni resetear contraseñas de cuentas existentes; rechazar correos duplicados sin sugerir un formulario de Equipo que ya no estará disponible.
S5. Aplicar autorización server-side de owner/admin (y mantener el patrón existente de soporte de platform admin), aislamiento al tenant de la ruta, validación de email único y transacción para cuenta/membresía/perfil. El token debe caducar y ser de un solo uso. Tras completar contraseña desde el token válido, marcar correo verificado sin habilitar verificación global a usuarios no relacionados.
S6. No añadir dependencias ni migraciones. Mantener las interfaces/copy institucional en español, tests PHPUnit y convenciones Laravel existentes. No cambiar estado de correo verificado de usuarios existentes que ya tengan cuenta.
